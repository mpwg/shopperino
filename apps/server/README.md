# Server Host

Dieser Ordner ist der Platzhalter fuer den spaeteren Self-hosted Server.

Der Server soll:

- HTTP-Endpunkte bereitstellen
- Uploads entgegennehmen
- Use Cases aus `packages/application` aufrufen
- einen Store aus `packages/db` injizieren
- keine eigene Fachlogik enthalten

Im ersten Implementierungsschritt wird bewusst noch kein HTTP-Framework eingebunden.
